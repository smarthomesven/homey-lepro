Add your Lepro lights to Homey and use all of your lights in your Flows. If any light that you use is missing, please let me know in the forum topic! Note that Lepro only allows one connection per account, so it's recommended to create a second Lepro account and share your devices with that account using Lepro's "Share" feature. This way, you can keep using both Homey and the Lepro mobile app.
